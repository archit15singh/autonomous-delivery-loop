# How comparable upstream PRs reached merge

On November 21, 2026, we screened up to 25 recently opened merged PRs in each of the 12 repositories where the factory had submitted a PR. We widened searches for fork contributions in repositories where recent examples were mostly internal or automated. We inspected the GitHub timelines, merge actors, final head checks, and contribution rules for 28 selected merges, including 23 fork PRs. For the two smaller SWE-bench repositories, the public history returned six merges each, all from same-repository branches. We also checked all 32 factory submissions on GitHub. This sample shows paths that maintainers have used. It cannot establish historical rule enforcement, private review, who approved a hosted workflow run, or a probability of merge.

The factory's reproducible search collected 421 merged PRs on the exact target branches over a one-year lookback, capped at 50 examples per branch. Of those, 126 were classified as external fork PRs. The sb-cli sample returned zero on the current target branch in that window. Issue-specific lookups independently checked 19 explicitly linked issues and found zero alternate merged closing PRs. All 32 factory submissions were still open. Run `upstream-merges` with `--days 365 --limit 50` to repeat the sweep from a fresh CI receipt. GitHub's linked-issue timelines showed no same-repository merged replacement for the factory's open issues where a closing issue was linked and the last 20 relevant events were visible. Some PRs lack a formal issue link. Search those by behavior and path before deciding whether a newly merged PR supersedes the change. For example, the [act Docker auth issue](https://github.com/nektos/act/issues/6236) has a merged downstream [workaround](https://github.com/dil-eight/runnir/pull/58) and remains open upstream.

Historical merges can guide the evidence and review workflow. Use current branch rules, exact head checks, and review to decide whether a live PR needs action. Follow through until GitHub records an upstream merge, a closure, or a human-owned blocker. [Factory follow-up procedure](ci-follow-up.md)
